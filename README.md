# NewProjectBlog - سیستم مدیریت محتوای جنگویی

یک پلتفرم بلاگینگ کامل و کاربردی ساخته شده با Django که امکان انتشار محتوا، مدیریت کاربران و تعامل با خوانندگان را فراهم می‌کند. این پروژه به عنوان یک پروژه آموزشی برای تسلط بر مفاهیم پیشرفته Django توسعه داده شده است.

## 📖 خلاصه پروژه

NewProjectBlog یک سیستم مدیریت محتوای جامع است که به کاربران اجازه می‌دهد پست‌های وبلاگ ایجاد کنند، محتوا را دسته‌بندی کنند، نظرات مدیریت کنند و با خوانندگان تعامل داشته باشند. این پروژه تمرینی شامل سیستم احراز هویت پیشرفته، مدیریت رسانه، جستجوی پیشرفته و پنل ادمین کاملاً سفارشی شده است.

## ✨ ویژگی‌های کلیدی

### 📝 مدیریت محتوا
- **سیستم پست‌ها**: ایجاد، ویرایش، حذف و انتشار پست‌ها با وضعیت‌های مختلف (پیش‌نویس، منتشر شده، رد شده)
- **دسته‌بندی محتوا**: دسته‌بندی پست‌ها در گروه‌های مختلف (تکنولوژی، برنامه‌نویسی، هوش مصنوعی، بلاکچین)
- **مدیریت تصاویر**: آپلود و مدیریت تصاویر با قابلیت resize اتوماتیک
- **زمان مطالعه**: محاسبه و نمایش زمان تخمینی مطالعه هر پست

### 👥 سیستم کاربری
- **احراز هویت کامل**: ثبت نام، ورود، بازیابی رمز عبور
- **پروفایل کاربری**: مدیریت اطلاعات شخصی و عکس پروفایل
- **سطح دسترسی**: تفکیک دسترسی کاربران عادی و ادمین
- **ویرایش حساب**: امکان ویرایش اطلاعات کاربری و حساب

### 💬 تعاملات
- **سیستم کامنت**: امکان کامنت گذاری و مدیریت نظرات
- **فرم تماس**: سیستم تیکت برای ارتباط با مدیریت
- **جستجوی پیشرفته**: جستجو در عنوان و محتوای پست‌ها

### 🎨 ویژگی‌های فنی
- **پنل ادمین سفارشی**: مدیریت کامل محتوا و کاربران
- **pagination**: صفحه‌بندی خودکار پست‌ها
- **قالب‌بندی Markdown**: پشتیبانی از قالب‌بندی پیشرفته
- **تگ‌های سفارشی**: فیلتر کردن و علامت‌گذاری محتوا

## 🛠️ تکنولوژی‌های استفاده شده

### Backend
- **Django 5.0.6** - فریمورک اصلی backend
- **django-resized** - مدیریت و resize اتوماتیک تصاویر
- **django.contrib.postgres** - آماده‌سازی برای PostgreSQL

### Frontend
- **HTML5** - ساختار صفحات
- **CSS3** - استایل‌دهی
- **JavaScript** - تعاملات frontend

### Database
- **SQLite3** - پایگاه داده توسعه

### سایر ابزارها
- **Markdown** - پردازش محتوای متنی
- **Pillow** - پردازش تصاویر

## 🚀 راه‌اندازی و نصب

### پیش‌نیازها
- Python 3.8 یا بالاتر
- pip (مدیریت پکیج‌های پایتون)
- virtualenv (توصیه شده)

### مراحل نصب

1. **کلون کردن پروژه**
   ```bash
   git clone https://github.com/alimohammadiam/NewProjectBlog.git
   cd NewProjectBlog
   ```

2. **ایجاد و فعال‌سازی محیط مجازیه**

   ```bash
     python -m venv venv

    .\venv\Scripts\activate

   ```


3. نصب dependencies

 ```bash
    pip install -r requirements.txt
   ```

4. اجرای migrations

   ```bash
    python manage.py migrate
   ```

5. ایجاد کاربر ابرمدیر

   ```bash
    python manage.py createsuperuser
   ```

6. اجرای سرور توسعه

   ```bash
    python manage.py runserver
   ```

7. دسترسی به برنامه

 - برنامه: http://localhost:8000/blog/
 - پنل ادمین: http://localhost:8000/admin/

```text
  NewProjectBlog/

│   ├── templatetags/      # فیلترها و تگ‌های سفارشی
│   ├── models.py          # مدل‌های دیتابیس
│   ├── views.py           # ویوهای اپلیکیشن
│   ├── urls.py           # URLهای اپلیکیشن
│   ├── forms.py          # فرم‌های اپلیکیشن
│   └── admin.py          # تنظیمات پنل ادمین
├── templates/             # تمپلیت‌های پروژه
│   ├── blog/             # تمپلیت‌های اپ بلاگ
│   ├── forms/            # تمپلیت‌های فرم‌ها
│   ├── partials/         # کامپوننت‌های قابل استفاده مجدد
│   └── registration/     # تمپلیت‌های احراز هویت
├── media/                # فایل‌های رسانه آپلود شده
│   ├── account_images/   # عکس‌های پروفایل
│   └── post_images/      # عکس‌های پست‌ها
├── static/              # فایل‌های استاتیک
└── requirements.txt     # dependencies پروژه
```

### 🔧 مدل‌های اصلی

- مدیریت محتوای اصلی وبلاگ
- وضعیت‌های مختلف (پیش‌نویس، منتشر شده، رد شده)
- دسته‌بندی و زمان مطالعه
- قسمت slug خودکار برای SEO

### 👤 Account (حساب کاربری)

- اطلاعات تکمیلی کاربران
- تاریخ تولد، بیو، شغل و عکس پروفایل
- ارتباط یک به یک با مدل User جنگو

### 💬 Comment (نظر)

- سیستم کامنت با تایید ادمین
- مدیریت نظرات فعال و غیرفعال
- زمان‌بندی ایجاد و به‌روزرسانی


### 🎫 Ticket (تیکت)

- مدیریت تصاویر پست‌ها
- قسمت resize اتوماتیک تصاویر
- حذف خودکار فایل‌های فیزیکی


### 🌐 URLهای اصلی

- `/blog/` - صفحه اصلی
- `/blog/posts/` - لیست تمام پست‌ها
- `/blog/posts/<category>/` - پست‌های دسته‌بندی خاص
- `/blog/posts/detail/<id>/` - جزئیات پست
- `/blog/profile/` - پروفایل کاربری
- `/blog/search/` - جستجوی پست‌ها
- `/blog/ticket` - فرم تماس
